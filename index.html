Adsorption assistant

Ask how strongly CO₂, CO or SO₂ sticks to a metal surface. You get the calculated energy, a plain explanation, and the simulation files to reproduce it.

Energies come from density functional theory calculations with Quantum ESPRESSO (PBE, no dispersion correction). New to this? Read the help page. Code and data are open on GitHub.
